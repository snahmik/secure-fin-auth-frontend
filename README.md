# Secure Fin Frontend

A secure financial management dashboard built with React and Vite.

**Production Server:** https://secure-fin-auth-frontend-production.up.railway.app/

---

## Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Environment Setup

Create a `.env` file in the root directory and define the variables as shown in `.env.example`:

```env
VITE_API_URL=your_api_url_here
```

### Development

Start the frontend development server:

```bash
npm run dev
```
